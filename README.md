# OUR LITTLE WORLD

> 포켓몬 세계관으로 풀어낸 세 사람의 인터랙티브 팀 소개 웹사이트

`OUR LITTLE WORLD`는 세 명의 팀원을 포켓몬 캐릭터로 재해석한 반응형 팀 소개 프로젝트입니다. 사용자는 김박사의 연구소에 방문해 실루엣 속 파트너를 만나고, 포켓볼을 열어 캐릭터의 정체와 이야기를 발견합니다.

도감에서 만난 규이리·익상해씨·영부기는 스토어의 포토카드, 스티커, 포스터로 이어집니다. 팀원 정보를 단순히 나열하는 대신, 사용자가 직접 선택하고 탐색하며 각자의 개성과 에피소드를 알아가도록 설계했습니다.

## 사용자에게 전하고 싶은 경험

- 실루엣 속 캐릭터에 대한 궁금증
- 포켓볼을 직접 선택하는 참여감
- 실제 팀원과 포켓몬이 결합된 이미지의 반전
- 특성과 추가 정보를 하나씩 열어보는 발견의 재미
- 마음에 드는 캐릭터의 굿즈를 구경하는 수집 경험

사이트 전체는 **연구소 방문 → 파트너 발견 → 도감 탐색 → 굿즈 구경**으로 이어지는 하나의 짧은 모험입니다.

## 랜딩 페이지 이용 흐름

### 1. 김박사의 연구소 방문

첫 화면에서는 “서로 다른 우리가 만나, 하나의 모험이 되다”라는 메시지를 중심으로 팀의 분위기와 프로젝트 세계관을 소개합니다.

### 2. 실루엣 속 파트너 발견

화면을 내리면 세 캐릭터가 실루엣으로 먼저 등장합니다. 모습을 바로 공개하지 않고 도감으로 이동하도록 유도해 다음 화면에 대한 기대감을 만듭니다.

### 3. 포켓볼 선택

도감에서는 세 개의 포켓볼 중 하나를 선택할 수 있습니다. 포켓볼을 누르면 열림 효과와 함께 캐릭터가 화면에 등장하고, 캐릭터 이미지와 도감 정보가 서로 반대 방향에서 진입합니다.

### 4. 캐릭터 정보 탐색

상세 화면에서는 타입, 키, MBTI 분류, 특성, 실제 경험을 확인할 수 있습니다. 특성 옆의 물음표를 누르면 숨겨진 설명이 나타나며, 이전·다음 버튼으로 다른 캐릭터를 연속해서 살펴볼 수 있습니다.

### 5. 파트너 굿즈 확인

도감의 상품 보기 버튼을 누르면 해당 캐릭터의 상품으로 연결됩니다. 스토어에서는 세 캐릭터의 포토카드, 원형 스티커, 미니 포스터를 확인할 수 있습니다.

## 세 명의 파트너

| 캐릭터 | 팀원 | 도감 번호 | 타입 | 분류 | 특성 | 소개 문구 |
| --- | --- | --- | --- | --- | --- | --- |
| **규이리** | 한영민 | No. 0004 | 불꽃 | ESFP | 오뚜기 | 작은 불꽃, 커다란 열정 |
| **익상해씨** | 고범규 | No. 0001 | 풀·독 | INFJ | 오타쿠 | 함께 자라는 우리들의 모험 |
| **영부기** | 최익준 | No. 0007 | 물 | INFP | 부족한 | 어디든 함께할 든든한 친구 |

### 규이리 — 불꽃 타입

한영민을 파이리 콘셉트로 표현한 캐릭터입니다. 쉽게 좌절하지 않는 성격을 `오뚜기`라는 특성으로 표현했고, 카리나와 대화한 경험과 스위스 여행 등을 도감 정보에 담았습니다.

### 익상해씨 — 풀·독 타입

고범규를 이상해씨 콘셉트로 표현한 캐릭터입니다. 프라모델 수집과 여행을 좋아하는 특징을 살려 자신만의 세계를 가진 캐릭터로 구성했습니다.

### 영부기 — 물 타입

최익준을 꼬부기 콘셉트로 표현한 캐릭터입니다. 인도 여행, 개명, 야생 멧돼지를 1m 앞에서 마주친 경험 등 독특한 에피소드를 도감 정보에 담았습니다.

## 화면을 재미있게 만든 장치

- **선택에 반응하는 포켓볼:** 닫힌 포켓볼이 열리고 캐릭터가 화면으로 튀어나오는 발견 인터랙션입니다.
- **캐릭터별 테마 색상:** 규이리는 주황색, 익상해씨는 초록색, 영부기는 파란색을 사용합니다.
- **숨겨진 특성 설명:** 물음표 버튼을 누르면 캐릭터의 특성에 대한 추가 설명이 나타납니다.
- **효과음과 배경음악:** 포켓볼 열기, 캐릭터 등장, 버튼 선택 등의 동작에 소리를 연결해 몰입감을 높였습니다.

## 연구소 안의 주요 공간

### HOME

팀의 메시지와 세계관을 소개하는 첫 화면입니다. 세 캐릭터의 실루엣을 보여주고 도감으로 이동하도록 안내합니다.

### POKÉDEX

포켓볼을 선택하고 캐릭터의 상세 정보를 확인하는 핵심 공간입니다. 마우스와 키보드로 조작할 수 있으며, URL을 통해 특정 캐릭터로 바로 접근할 수 있습니다.

### STORE

세 캐릭터를 활용한 총 9개의 굿즈와 상세 설명을 확인할 수 있는 공간입니다.

- 포토카드 3종
- 원형 스티커 3종
- 미니 포스터 3종

## 구현에서 중요했던 부분

- 캐릭터 이동과 도감 등장을 하나의 연속 애니메이션으로 연결
- 애니메이션 도중 `Escape`를 눌러도 선택 화면이 정상적으로 복구되도록 처리
- 브라우저 뒤로 가기·앞으로 가기와 캐릭터 선택 상태를 연동
- 이미지 로딩 실패 시 재시도할 수 있도록 예외 처리
- 모바일에서 캐릭터와 정보를 세로로 배치
- 긴 정보가 다음 열을 침범하지 않도록 도감 레이아웃 조정
- `prefers-reduced-motion`을 통한 동작 줄이기 설정 지원
- `Enter`, `Space`, `Escape`를 활용한 키보드 조작 지원

## 로컬에서 실행하기

```bash
git clone https://github.com/gobeomgyu/team-assignment-01.git
cd team-assignment-01
npm install
npm run dev
```

Vite 기본 경로는 `/team-assignment-01/`입니다. Windows PowerShell에서 실행 정책 오류가 발생하면 `npm.cmd install`, `npm.cmd run dev`를 사용하세요.

## 품질 확인

```bash
npm run build
npm run test:e2e
```

Playwright를 이용해 데스크톱과 모바일 환경에서 다음 항목을 확인합니다.

- 홈과 도감 사이의 이동
- 포켓볼 선택과 캐릭터 등장
- 이전·다음 탐색과 특성 설명
- 브라우저 히스토리와 키보드 조작
- 이미지 오류 복구
- 스토어 상품 목록과 상세 화면
- 화면 너비 변경 시 레이아웃 안정성

## 협업 방식

팀원들의 변경 사항은 GitHub의 `main` 브랜치를 통해 공유했습니다. 새로운 작업을 시작하기 전 원격 코드를 pull하고, 작업이 완료되면 빌드와 자동화 테스트를 통과한 변경만 커밋·푸시하는 흐름으로 진행했습니다.

`main`에 새 커밋이 푸시되면 GitHub Actions가 프로젝트를 빌드하고 GitHub Pages에 배포합니다.

## 이 프로젝트가 보여주는 것

이 프로젝트는 팀원 소개도 하나의 놀이와 탐색 경험으로 만들 수 있다는 생각에서 시작했습니다.

세 명의 팀원은 단순한 프로필 카드가 아니라 각자의 타입과 특성, 경험을 가진 캐릭터로 등장합니다. 사용자는 직접 포켓볼을 선택하고 도감과 스토어를 탐색하며 우리를 발견합니다.

홈·도감·스토어가 하나의 세계관으로 연결되고, 팀의 개성과 유머·애니메이션·접근성·반응형 설계가 하나의 웹 경험으로 결합되는 것이 프로젝트의 핵심입니다.
